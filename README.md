# Inventory-Manager-Application

A robust, CLI-based Inventory Management System built with Python. This application provides retail managers with an intuitive interface to track stock levels, process sales and deliveries, generate data-driven reports, and maintain an audit log of all system transactions.

## 🚀 Features
The system features a complete, interactive 11-option menu designed to streamline daily store operations:

### 📦 Product Management
* **View All Products:** Display a complete, organized list of everything currently in inventory.
* **Add New Product:** Easily introduce new inventory items to the database.
* **Update Product Details:** Modify existing product information (names, categories, pricing).
* **Remove Product:** Permanently delete products that are no longer being carried.
* **Search Products:** Quickly locate specific items using advanced filtering or keywords.

### 📈 Stock & Transaction Controls
* **Update Stock (Sale/Delivery):** Keep inventory levels accurate by adding new shipments or deducting stock upon customer sales.
* **View Transaction Log:** Track user history and maintain an accurate audit trail of updates, additions, and sales.

### 📊 Reporting & Automation
* **View Low Stock Alerts:** Prevent stockouts with automated flags for items falling below safety-stock thresholds.
* **View Category Report:** Analyze inventory distribution and values categorized by department.
* **Export Reports:** Export critical store data and reports (e.g., CSV or TXT formats) for external analysis.

### 💾 Data Persistence
* **Save & Exit:** Automatically commits and saves all updates securely before closing the program.

---

### 🛠️ Tech Stack
* **Language:** Python 3.x
* **Storage:** JSON, CSV
